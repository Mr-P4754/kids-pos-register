# お店屋さんごっこPOSレジシステム (Kids POS Register System)

ブラウザひとつ・オフライン環境で快適に動作する、お店屋さんごっこ・教育・イベント・店舗向けWeb POSレジシステムです。PWA（Progressive Web Apps）に対応しており、PC・iPad/タブレット・スマートフォンへインストールしてネイティブアプリのように利用できます。

👉 **[🌐 Webアプリを開く（GitHub Pages）](https://mr-p4754.github.io/kids-pos-register/)**

---

## 🌟 主な機能と特長

1. **実用的なPOSレジ画面**
   - 商品タイルをタップするだけでカートに追加
   - カテゴリフィルタ・商品検索・割引適用（10%引・半額・値引き等）対応
   - 電卓風テンキー & 金種別ワンタップボタン（1,000円、5,000円、10,000円、ぴったり）によるお預かり金入力
   - 巨大おつり表示モーダル（渡し間違い防止、タップで即次客対応へ）

2. **内蔵カメラによるバーコード／QRコードスキャン**
   - スマートフォンやPCのカメラを利用して商品バーコードを直接読み取り・即時カート追加
   - レジカメラから複数端末の売上合算QRコードの読み取りにも対応

3. **バーコード＆値札ラベルシート印刷**
   - A4用紙やラベルシール（24面・44面等）にぴったり収まるバーコード付き商品ラベルをブラウザから一括印刷
   - 普通紙でもハサミでカットしやすい切り取りガイド点線表示に対応

4. **売上分析 & 取引取消（VOID）**
   - 売上総額・客数・平均客単価・時間帯別グラフ・商品別売上ランキングをリアルタイム可視化
   - 誤会計の取引取消（VOID）による売上・客数・在庫の自動巻き戻し
   - UTF-8 BOM付きCSVエクスポート（Excelでそのまま開ける形式）

5. **複数端末の売上データ合算**
   - 高密度QRコードによる端末間オフライン合算
   - JSONファイルのドラッグ＆ドロップによる一括集計

6. **PWA（Progressive Web Apps） & 完全オフライン動作**
   - Service Workerによるキャッシュ制御で、通信環境のない野外や催事場でも快適動作
   - ホーム画面に追加して全画面アプリとして起動可能

## 🚀 使い方

### 1. ブラウザでアクセス
[https://mr-p4754.github.io/kids-pos-register/](https://mr-p4754.github.io/kids-pos-register/) にアクセスするだけで、すぐにレジとして利用開始できます。

### 2. ホーム画面に追加（PWAインストール）
- **iOS (Safari)**: 共有ボタン →「ホーム画面に追加」
- **Android (Chrome)**: メニューまたはヘッダーの「アプリ保存」→「インストール」
- **PC (Chrome/Edge)**: アドレスバー右側のインストールアイコンをクリック

### 3. 初期商品・独自商品の登録
- 「システム設定」タブから店舗名や初期プリセット（縁日・文具・カフェ・駄菓子屋等）の選択、新規商品の自由な登録・編集が可能です。

## 🛠️ 技術スタック
- **Frontend**: HTML5, Vanilla JavaScript (ES6+), CSS3
- **CSS Framework**: Tailwind CSS (CDN), FontAwesome 6
- **ライブラリ**:
  - `html5-qrcode`: カメラバーコード/QRコード読み取り
  - `JsBarcode`: バーコード（JAN-13/CODE128）生成
  - `qrcode-generator`: 高密度QRコード生成
- **PWA**: Service Worker, Web App Manifest, Cache API, LocalStorage
- **ホスティング**: GitHub Pages
