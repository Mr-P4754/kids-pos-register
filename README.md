# 🏪 こども バーコードPOSレジ おみせやさん (Kids Barcode POS Register)

バーコードを「ピッ！」とお買い物＆本格的な知育お金計算ができる、子ども向けのお店屋さんごっこWeb POSレジシステムです。
ブラウザ完結・完全オフライン（PWA）対応で、iPadやタブレット、スマートフォン、PCで本物のセルフレジのように楽しく遊べます！

👉 **[🌐 Webアプリを開く（GitHub Pages）](https://mr-p4754.github.io/kids-pos-register/)**

---

## 🌟 主な機能と特長

1. **🛒 本物そっくり！お買い物カゴ ＆ 商品スキャン**
   - 画面左半分が「お買い物カゴ」、右半分が「商品一覧」の左右分割2ペイン構成
   - 商品ボタンをタップするだけで効果音（ピッ！）とともにカゴに追加
   - スムーズな縦スクロールで、商品が増えても快適に操作可能

2. **🏷️ バーコードカード印刷 ＆ カメラ・リーダー対応**
   - **A4用紙印刷**: 商品バーコードカードをA4用紙に一括印刷。ハサミで切り取って商品に貼れば本格的なお店屋さんごっこが完成！
   - **カメラ読み取り**: スマホ・タブレットの内蔵カメラでバーコードをスキャン
   - **USB/Bluetoothリーダー対応**: 市販のHIDバーコードスキャナーを接続して「ピッ！」と即座に商品を読み取り可能

3. **🪙 日本の全9金種に対応した知育お金トレイ**
   - **硬貨（6種）**: 1円玉、5円玉、10円玉、50円玉、100円玉、500円玉
   - **紙幣（3種）**: 1,000円札、5,000円札、10,000円札
   - 本物のレジ引き出し（キャッシュドロワー）のように小銭と紙幣が綺麗に並ぶ2段レイアウト
   - タップで1枚投入、＋／－ボタンで投入枚数の微調整が可能
   - **「🎯 ぴったりはらう（自動セット）」**: 1円単位の端数まで最適な硬貨・お札を自動計算してセット

4. **🛍️ セルフレジ風知育ギミック ＆ 音声ガイド（おしゃべりレジ）**
   - **レジ袋ギミック**: 「レジぶくろ いる？ (+5円)」の選択とレシート反映
   - **ポイントカードギミック**: 「ポイントカード ピッ！ (+1P)」の知育演出
   - **音声読み上げ（Web Speech API）**: 「いらっしゃいませ！」「しゃけのおにぎり 140円です！」「おつりは ○○円です！」など元気におしゃべり

5. **🧾 本格レシート発行 ＆ お祝い紙吹雪**
   - お会計完了時にファンファーレとともに画面いっぱいの紙吹雪（Confetti）でお祝い！
   - 店名・日付・購入商品・お預かり・おつりが印字されたリアルなギザギザフチのレシートを表示・印刷

6. **🏪 お店・商品のカスタマイズ**
   - プリセット切り替え: 「24じかん こどもコンビニ」「かわいい おかしやさん」「やきたて パンやさん」「しんせん やおやさん」
   - 「とうろく・せってい」から商品名・絵文字・ねだん（1円〜99,999円）・初期在庫を自由に登録可能
   - 重複しないバーコード番号を自動発行

7. **📱 PWA（Progressive Web Apps） ＆ 完全オフライン動作**
   - Service Worker ＆ Web App Manifest 対応
   - インターネットのない環境（公園・車内・移動中）でも完全オフラインで動作
   - ホーム画面に追加して全画面ネイティブアプリ感覚で遊べます

## 🚀 使い方

### 1. ブラウザでアクセス
[https://mr-p4754.github.io/kids-pos-register/](https://mr-p4754.github.io/kids-pos-register/) にアクセスするだけで、すぐに遊べます。

### 2. ホーム画面に追加（PWAインストール）
- **iPad / iPhone (Safari)**: 共有ボタン →「ホーム画面に追加」
- **Android (Chrome)**: メニュー →「アプリをインストール」または「ホーム画面に追加」
- **PC (Chrome / Edge)**: アドレスバー右端のインストールアイコンをクリック

### 3. バーコードカードで遊ぶ
1. ヘッダーの「いんさつ」タブを開く
2. 「すべてのバーコードカードを印刷」ボタンを押す
3. A4用紙に印刷し、点線に沿って切り取っておもちゃに貼れば、本物のレジごっこがスタート！

## 🛠️ 技術スタック
- **Frontend**: HTML5, Vanilla JavaScript (ES6+), CSS3
- **Design & Icons**: Tailwind CSS, FontAwesome 6, Google Fonts (M PLUS Rounded 1c)
- **バーコードスキャン**: `html5-qrcode`
- **バーコード生成**: `JsBarcode`
- **紙吹雪エフェクト**: `canvas-confetti`
- **音声機能**: Web Audio API (レジ効果音), Web Speech API (音声ガイド)
- **PWA**: Service Worker, Web App Manifest, Cache API, LocalStorage
- **ホスティング**: GitHub Pages
